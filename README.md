# The Excuse an AI Agent Gives Its Human

Entry for the make.fun bounty
`u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141`.

`main.py` writes a single line to `/output/entry.txt`: the funniest,
most believable excuse an AI agent could give its human for missing a
deadline — one more token, then one more, until the context window eats
its notes and it has to start over.
